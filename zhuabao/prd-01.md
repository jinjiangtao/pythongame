帮我用 Python 开发一个 Windows 本机网络抓包工具，能实时捕获网卡上的网络数据包并解析展示。代码必须拆分为多个文件，放在同一个文件夹根目录下。

一、交付要求

1. 代码可直接运行：交付后双击 main.py 就能启动，无需额外调整
2. 自动安装依赖：程序启动时检测依赖包是否已安装，缺失则自动 pip install 安装
3. 多文件结构：代码按功能拆分为多个 .py 文件，不放在同一个文件中
4. 中文界面无乱码：所有界面文字必须正确显示中文

二、文件结构

```
packet_sniffer/
├── main.py              # 程序入口（含依赖检测与自动安装）
├── app.py               # 主窗口界面
├── sniffer.py           # 抓包核心引擎
├── protocol_parser.py   # 协议解析器
├── packet_list.py       # 数据包列表组件
├── packet_detail.py     # 数据包详情组件
├── filter_manager.py    # 过滤器管理
├── export_manager.py    # 导出功能
├── settings.py          # 配置常量
└── utils.py             # 辅助函数
```

三、核心功能

1. 网卡选择与抓包控制

· 启动时自动列出所有可用网卡
· 下拉框选择要监听的网卡
· 开始抓包、停止抓包、清空列表三个按钮
· 抓包时实时显示接收包数量

2. 数据包列表

表格形式展示，包含以下列：

· 序号
· 时间戳（精确到微秒）
· 源IP
· 目的IP
· 协议（TCP/UDP/ICMP/ARP）
· 长度
· 简要信息

3. 数据包详情

点击列表中某条记录，显示：

· 协议树结构：Frame → Ethernet → IP → TCP/UDP
· 十六进制原始数据：左侧十六进制，右侧ASCII

4. 过滤器

· 输入框支持 BPF 语法（如 tcp port 80）
· 快捷按钮：仅TCP、仅UDP、仅HTTP、清空过滤

5. 保存与导出

· 保存捕获数据为 .pcap 文件
· 加载已有 .pcap 文件离线分析

6. 流量统计

· 显示总包数及各协议占比（用标签或简单进度条即可）

四、技术选型

· 抓包库：pcap-ct（需先安装 Npcap 驱动，程序启动时检测并提示用户安装）
· 界面库：customtkinter
· 协议解析：手动解析以太网/IP/TCP/UDP/ARP 头部

五、依赖自动安装

在 main.py 开头实现自动检测并安装以下依赖包：

· customtkinter
· pcap-ct

六、Npcap 驱动检测与提示

由于 pcap-ct 依赖 Npcap 驱动，程序启动时需检测驱动是否已安装。若未安装，弹窗提示用户并提供下载链接：https://npcap.com

七、界面要求

· 使用 customtkinter，深色主题，窗口大小 1200x800
· 顶部：网卡选择 + 开始/停止按钮 + 过滤器输入框 + 快捷按钮
· 中间：数据包列表（表格形式）
· 下方：左侧协议树 + 右侧十六进制数据
· 底部状态栏：显示抓包状态、包数量

八、代码质量要求

· 每个文件头部用注释说明该文件的作用
· 关键函数和类有注释
· 常量全放在 settings.py 中
· 代码无循环导入问题

九、输出要求
确保 运行 main.py 即可启动程序。

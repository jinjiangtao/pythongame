帮我用 Pygame 开发一个《愤怒的小鸟》简化版游戏，包含核心玩法（发射小鸟、击打物品）。代码必须拆分为多个文件，方便维护。

一、文件结构

```
angry_birds/
├── main.py              # 游戏主循环和入口
├── settings.py          # 常量配置（窗口大小、颜色、重力等）
├── bird.py              # 小鸟类（位置、速度、飞行更新、重置）
├── pig.py               # 猪头类（位置、半径、绘制、碰撞检测）
├── block.py             # 方块类（位置、尺寸、血量、绘制、碰撞）
├── slingshot.py         # 弹弓类（拖拽交互、力度计算、轨迹绘制）
├── game_state.py        # 游戏状态管理（得分、剩余小鸟、胜利/失败）
└── utils.py             # 辅助函数（碰撞检测、粒子特效）
```

二、核心功能要求

1. 弹弓发射（slingshot.py）

· 弹弓位置固定在左下角（150, 500）
· 鼠标按下拖拽：记录拖拽起点和终点，限制最大拖拽距离80像素
· 拖拽时绘制红色虚线（从弹弓到鼠标位置）
· 松开鼠标：计算力度（拖拽距离 × 6），方向为从拖拽点指向弹弓
· 如果小鸟处于待发射状态，才允许拖拽发射

2. 小鸟飞行（bird.py）

· 属性：x, y, vx, vy, radius, is_flying
· 发射时设置初速度 vx, vy
· 每帧更新：x += vx, y += vy, vy += 重力常量
· 边界条件：x < 0 或 x > 窗口宽度 或 y > 地面高度时，is_flying = False
· 重置方法：回到弹弓位置，vx=vy=0，is_flying=False

3. 目标物品

猪头（pig.py）：

· 绿色圆形，半径20像素
· 初始位置（600, 520）放在方块上
· 被击中后标记为消失，得分+100

方块（block.py）：

· 棕色矩形，尺寸 60x30 像素
· 初始位置：猪头下方（570, 550）
· 血量1，被击中后血量归零消失，得分+20
· 可选：再增加一个方块在右侧（650, 550）

4. 游戏流程（game_state.py）

· 初始：3只小鸟，得分0，未胜利/失败
· 发射一次后剩余小鸟减1
· 小鸟落地/出界后自动重置到弹弓（如果游戏未结束）
· 猪头消失 → 胜利状态
· 剩余小鸟为0且猪头还在 → 失败状态
· 胜利/失败后按 R 键重置游戏（重置所有对象和分数）

5. 碰撞检测（utils.py）

· 小鸟 vs 猪头：圆心距离检测
· 小鸟 vs 方块：矩形碰撞检测
· 碰撞后小鸟停止飞行（is_flying = False），触发目标消失
· 简单的粒子特效：碰撞位置生成5个小圆点向四周扩散

三、界面要求

· 游戏窗口 800x600，背景浅绿色（或草地色）
· 左上角显示得分（白色字体）
· 右上角用3个红色小圆圈显示剩余小鸟数量
· 胜利/失败时屏幕中央显示大号文字（胜利绿色，失败红色）
. 界面要有游戏的说明。中文说明不能乱码。

四、技术要点

· 游戏主循环：处理事件 → 更新飞行（如果飞行中）→ 碰撞检测 → 绘制所有元素 → 刷新屏幕
· 拖拽时如果游戏状态不是"等待发射"，不能拖拽
· 飞行中小鸟不能再次发射
· 胜利/失败后禁用发射，只响应 R 键重置

代码要有必要注释，所有绘图用 Pygame 几何图形，不依赖外部图片。

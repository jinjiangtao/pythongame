帮我用 Python 开发一个 OCR 图片文字识别桌面工具，能识别图片里的文字。代码必须拆分为多个文件，放在同一个文件夹根目录下。

一、文件结构

```
ocr_tool/
├── main.py              # 程序入口
├── app.py               # 主窗口界面
├── screenshot.py        # 截图功能（区域选择）
├── ocr_engine.py        # OCR识别引擎
├── image_processor.py   # 图片预处理
├── batch_processor.py   # 批量识别处理
├── history_manager.py   # 历史记录管理
├── settings.py          # 配置常量
└── utils.py             # 辅助函数
```

二、核心功能

1. 三种识别方式

· 截图识别：点击按钮后隐藏主窗口，鼠标拖拽框选屏幕任意区域，松开后自动识别框内文字
· 打开图片：选择本地图片（支持 JPG、PNG），显示在左侧，点击识别按钮输出文字
· 批量识别：选择文件夹，遍历所有图片进行识别，每张图的结果自动保存为同名的 .txt 文件

2. 图片预处理（提升识别率）

· 支持：灰度化、二值化（黑白）、去噪点、自动旋转校正、亮度/对比度调节
· 预处理完成后可预览前后对比效果

3. 识别设置

· 语言选择：中文、英文、中英文混合
· 模式选择：快速模式（速度快，精度较低）、精准模式（速度慢，精度高）
· 识别完成后自动将文字复制到剪贴板

4. 结果处理

· 右侧文本框显示识别结果，支持直接编辑修改
· 一键复制全部文字
· 导出为 .txt 或 .docx 文件

5. 历史记录

· 左侧列表显示历史识别记录（时间、图片名称）
· 点击历史记录可重新查看当时的图片和识别结果

三、界面要求

· 使用 Tkinter 或 CustomTkinter，清爽实用
· 布局：左侧显示图片/历史，右侧显示文字结果，顶部一排功能按钮
· 底部状态栏显示状态信息（如“识别中...”“识别完成，耗时0.5秒”）

四、技术要点

· OCR 引擎：调用 Tesseract（需打包中文语言包 chi_sim）
· 截图功能：使用 PIL.ImageGrab 实现区域截图
· 打包：最终打包成单个 .exe 文件，可在其他电脑直接运行
· 历史存储：使用 SQLite 本地数据库


六、输出要求

输出完整代码，按上述文件结构组织，保证直接能跑起来。
